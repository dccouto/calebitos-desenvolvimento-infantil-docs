## Escopo do produto (refletido nos textos)

- Offline-first; **sem backend** próprio
- **Sem anúncios** / sem tracking de ads
- **Sem dados médicos**
- Dados locais: perfil, progresso, acessibilidade
- Compras Premium via **Google Play** + **RevenueCat**

## GitHub Pages

O repositório está preparado para Pages (Jekyll + tema `minima`, arquivos na raiz, `_config.yml`).

Para publicar:

1. No GitHub: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / pasta `/` (root)
4. Site esperado: `https://dccouto.github.io/calebitos-desenvolvimento-infantil-docs/`

Enquanto as Pages não estiverem ativas, use os links Markdown acima no GitHub.
